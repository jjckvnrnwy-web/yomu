# yomu

AIとのロールプレイ／小説セッションのログを、本文中心で読み返すためのビューア。

## 使い方

1. `index.html` をブラウザで開く（サーバー不要）
2. 書き出したテキストファイルを選ぶか、貼り付けて「取り込む」
3. モデルの出力が本文としてつながって表示され、自分の指示は `◆ 指示` として折りたたまれる。タップで開く

## 対応している書式

行頭の見出し（`:` / `：` のどちらでも可、`**太字**` や `#` 付きでも可）で発言を区切る。

| 役割 | 見出しの例 | 扱い |
| --- | --- | --- |
| ユーザー | `ユーザー:` `Prompt:` `User:` `あなた:` | 折りたたみ |
| モデル | `モデル:` `Response:` `Gemini:` `Model:` | 本文 |
| 思考 | `Thinking:` `Thoughts:` `思考:` | 捨てる |

見出しが一つもなければ全体を本文として扱う。

## 機能

- 指示の表示：折りたたみ（冒頭を一行プレビュー）／全部開く／非表示
- 縦書き・横書き、文字サイズ、ダークモード
- 読んだ位置をセッションごとに記憶
- 「保存」で整形済みの単体HTMLを書き出し

取り込んだログはブラウザ内（localStorage）にだけ保存される。元ファイルは手元に残しておくこと。
